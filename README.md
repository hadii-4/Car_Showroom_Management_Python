# Car Showroom Management System

A Python OOP based Car Showroom Management System developed as part of my Python learning journey.

## Features

- Add Car
- View Cars
- Search Car
- Remove Car
- Update Car
- Add Customer
- View Customers
- Sell Car
- View Sold Cars
- View Sales
- Save Cars to File
- Load Cars from File

## Concepts Used

- Python OOP
- Classes and Objects
- Constructors
- Methods
- Lists
- Loops
- Conditional Statements
- File Handling
- Functions
- Menu-driven Program

## Learning Progress

This project was developed during my first week of learning Python.

It helped me practice Python OOP and apply the concepts I learned in a practical project.
